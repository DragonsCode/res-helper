# Аудит продукта · 20 октября 2026

## Основание
Изучены React routes, формы, Context, API проектов/знаний, SQLAlchemy-модель,
документация миграции и бизнес-модели. В Chromium открыт настоящий локальный
FastAPI/React: обзор, проекты, библиотека, обсуждения, каталог, команда, настройки.
Снимки исходного состояния: `screenshots/before-desktop.png`, `before-mobile.png`.
Это экспертный аудит, не интервью с пользователями и не доказанная пользовательская гипотеза.

## Работа продукта
Re:Search связывает чтение научных источников с проектной работой. Исторический
хакатон был сообществом публикаций; действующая версия — приватные пространства,
проекты, задачи, материалы, обсуждения и редакционные учебные маршруты.
Ценность: сохранить контекст между вопросом, источником и совместной работой.

| Аудитория | Частая задача | Критическая цепочка |
|---|---|---|
| Интересующийся / журналист | Понять утверждение и найти первоисточник | Разбор → оригинал → заметка → ограничения |
| Студент / преподаватель | Освоить метод и повторить работу | Маршрут → проект → задачи → протокол → обсуждение |
| Исследователь | Согласовать воспроизводимую работу | Вопрос → метод → источники/данные → задачи → выводы |

## Обнаруженное
- Обзор начинается с большого рекламного блока; рабочие задачи уходят ниже первого экрана.
- 85 элементов p/span/small в основном содержимом desktop имеют размер менее 12 px.
- Пастель, повторяющиеся карточки и орбиты не объясняют данные.
- Аватары всего пространства повторены в каждом проекте, хотя назначения на проект нет.
- Процент относится только к задачам; не должен обозначать достоверность или готовность исследования.
- Нет отдельных полей вопроса, метода, ограничений и предварительных выводов.
- Материалы имеют реальные ссылки и заметки, но происхождение и связь с проектом слабо видны.
- Данные экспериментов не хранятся: рисовать экспериментальные графики сейчас было бы недостоверно.
- Некоторые сетевые ошибки чтения не имеют повтора; мобильное меню не удерживает фокус.
- Нативный dialog уже обеспечивает базовый keyboard focus, но не пространственные переходы.
- Существующие операции, роли, demo-isolation, редакционная атрибуция и BibTeX полезны и сохраняются.

## Новая архитектура опыта
Верхняя навигация пространства → рабочий журнал / проекты / библиотека / обсуждения.
Локальная навигация досье относится к конкретному проекту. Каталог — отдельная
читательская среда. На телефоне первыми идут текущие действия; меню — нативный dialog.

Реестр связывает проект, число материалов и выполнение задач. Карта состава
показывает реальные количества статей/наборов данных/заметок, с текстовой таблицей.
Она не оценивает доказательность, статистическую значимость или качество исследования.
Паспорт проекта хранит вопрос, метод, ограничения и выводы на сервере; пустое поле
остается явно незаполненным. Демонстрационные записи всегда отмечены как demo.

## Приоритет проверки
Создать проект → заполнить паспорт → сохранить/перезагрузить → добавить источник
→ выполнить задачу → обсудить; затем открытое чтение/учебный маршрут, смена режима,
поиск клавиатурой, приглашение/профиль. Для форм: ошибка без потери ввода, pending,
повтор; для чтения: loading/error/retry/empty; для всей среды: mobile/tablet/desktop.
