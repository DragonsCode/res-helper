# Laboratory ledger / дизайн-система

## Источники истины
- `frontend/src/design/tokens.css`: семантические цвета, шрифты, размеры, интервалы,
  радиусы, слои, motion duration/easing, документированные breakpoints.
- `frontend/src/design/motion.css`: взаимодействия и reduced-motion.
- `frontend/src/styles.css`: компоненты, сетки и адаптивные правила.
- `components/ui.jsx`: Button, Field, Modal, Avatar, EmptyState, Loading, реестр и разбор.

## Типографика и семантика
UI: Arial/Helvetica/system sans, основной размер 14 px. Документы и большие заголовки:
Georgia/Times, 16–19 px для чтения. Идентификаторы, подписи таблиц и числовые отношения:
системный monospace. Внешних шрифтов и запросов к font CDN нет.

Графит = рабочая оболочка. Кобальт = действие/ссылка/активное состояние.
Охра = требующее внимания, включая demo; красный = ошибка; тёмно-зелёный = завершённый
операционный статус. Значение всегда дублируется текстом, не только цветом.
Документы прямоугольные; контролы 4 px; dialog 8 px; аватары круглые.

Пробелы документов и линии реестров заменяют плитки. Один ответственный указан
по реальной модели данных; список участников пространства не выдается за команду проекта.

## Представление данных
Карта материалов — интерактивная таблица с интенсивностью заливки количества
связанных записей. Заголовки row/column и текстовые числа сохраняют смысл без цвета.
Ячейка открывает именно записи проекта и выбранного типа. Ноль — не кнопка.
Знаменатель прогресса — количество задач, а не оценка качества результата.
Пустые поля паспорта отображаются как «Не заполнено».

Таблицы отражают загруженные API-списки (лимиты существующего API описаны в
ARCHITECTURE.md). Для пилота с большими библиотеками нужна серверная пагинация
и отдельная агрегация; UI не должен заявлять исчерпывающую аналитику такого пространства.

## Motion: информация, которую передаёт движение
| Токен | Значение | Смысл |
|---|---|---|
| feedback | 120 ms | Hover подтверждает доступное действие, без сдвига соседей |
| control | 180 ms | Backdrop и подтверждение обозначают новый слой/результат |
| dismiss | 160 ms | Возврат из dialog без задержки следующего действия |
| disclosure | 240 ms | Паспорт переходит из чтения в редактирование в том же месте |
| spatial | 320 ms | Инспектор приходит справа, сохраняя контекст реестра |
| settle easing | cubic-bezier(.2,.8,.2,1) | Быстрое начало, мягкая остановка |

Press сдвигает только кнопку на 1 px; прогресс обновляется transform scaleX.
Native dialog сохраняет модальный фокус, Escape, фон и возврат фокуса. Его выход
завершается перед unmount. Инспектор использует opacity/translateX, обычный dialog —
opacity/scale(.98). Затемнение анимирует opacity при постоянном цвете фона,
чтобы не перерисовывать весь viewport на каждом шаге. will-change ограничен
открытыми dialog/backdrop. Переходы маршрутов сохраняют оболочку, переводят фокус в main
и не анимируют весь текст. Нет бесконечного декоративного движения.

Spring не добавлен: интерфейс не имеет перетаскиваемых физических объектов.
Это избегает неинформативного «подпрыгивания» формы или научного документа.
Reduced motion отключает анимации/переходы и задержку закрытия; pending остаётся
передан disabled/aria-busy и текстом, а не только вращением.

Значения проверяются в реальном Chromium: hover/press, opening/closing, reduced
motion. Это инженерная настройка, не результат сравнительного пользовательского
эксперимента и не обещание одинаковых FPS на любых устройствах.

## Адаптивность и доступность
Desktop: рабочий журнал 2.2:1, document/context split. Tablet: журнальная колонка
и две контекстные области ниже; чтение без узкой колонки. Mobile: задачи раньше
карты материалов, последовательные документы, меню в native dialog, формы в одну
колонку, инспектор занимает экран. Длинная таблица может прокручиваться локально.

Основные кнопки и input ≥44 px. Матрица также имеет 44 px цели. Skip link, явные
labels, focus-visible, осмысленный порядок заголовков, modal keyboard containment,
доступные empty/error/retry и сокращённое движение входят в компонентный контракт.
Axe не заменяет ручное тестирование скринридером и исследования с людьми.

## Формы и асинхронные операции
Создание/редактирование блокирует повторную отправку и закрытие во время pending.
Ошибка оставляет ввод, объясняет повтор. Паспорт сохраняется явно через отдельный
endpoint; редактирование общих метаданных проекта не стирает документ.
Паспорт предупреждает о несохранённом вводе при переходе по ссылке и закрытии вкладки.
Внутренние переходы и browser back/forward защищены useBlocker; для этого React
Router переведён на его data router API без смены стека. При смене пространства
также запрашивается подтверждение потери ввода.
