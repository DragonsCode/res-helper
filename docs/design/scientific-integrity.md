# Научная точность интерфейса

Re:Search организует исследовательскую работу. Сервис не проводит рецензирование,
не подтверждает гипотезы и не вычисляет достоверность научных утверждений.

- Задачи: числитель — done, знаменатель — все задачи проекта. Это операционная метрика.
- Карта материалов: число связанных записей каждого типа. Две ссылки не означают
  две независимые репликации; таблица не делает такой вывод.
- Паспорт: вопрос, метод, ограничения, предварительные выводы. Поля вводит автор
  или владелец пространства, пустота не заменяется сгенерированным текстом.
- Источник: автор/организация, URL, год, заметки, создатель записи, связь с проектом.
  DOI/URL не проверяется автоматически, сведения требуют сверки с оригиналом.
- Набор данных: сохранена ссылка и описание; экспериментальные значения не загружены.
  Поэтому графики измерений и статистический анализ не отображаются.
- Поддержка обсуждения: мнение участника, не научная оценка качества.
- Каталог: редакционные стартовые разборы с первоисточниками, не peer-reviewed статьи.
- Demo: постоянная пометка об учебных записях и вымышленных участниках; отдельная сессия.

Следующий обоснованный этап: импорт табличных данных с единицами, схемой, provenance,
пропусками и версионированием; только затем — графики наблюдений и воспроизводимый
анализ. Нужны также история изменений документов и связь отдельных утверждений
с конкретными фрагментами источников. Текущая версия этого не изображает.
