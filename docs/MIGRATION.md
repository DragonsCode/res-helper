# Перенос Django → FastAPI

Оригинальные каталоги `helper`, `users`, `res_helper`, `media`, файл `manage.py` и
снимок `db.sqlite3` перемещены в `legacy/django/`. Содержимое исходного снимка не
меняется; импорт открывает его с `mode=ro`.

## Процедура

1. Подготовьте новую БД через `uv run alembic upgrade head`.
2. Сохраните резервную копию целевой БД перед импортом в уже используемую среду.
3. Выполните из `backend`:

   ```bash
   uv run python -m app.cli import-legacy --source ../legacy/django/db.sqlite3
   ```

4. Проверьте отчёт с количеством перенесённых записей и войдите по прежнему логину.

Импорт одного неизменного снимка повторяем: SHA-256 снимка записывается в
`legacy_mappings`; повторный запуск возвращает `already_imported: true`.
Это импорт снимка, не непрерывная синхронизация. Другой снимок с уже существующими
email не объединяется автоматически: операция останавливается и откатывается.

## Соответствие данных

| Django | Новый продукт |
| --- | --- |
| `auth_user` | `User`, прежний username для входа, состояние активности |
| Все пользователи снимка | Участники отдельного архивного workspace |
| Первый активный superuser, либо первый активный пользователь | Владелец архивного workspace |
| `helper_post` | `Discussion` с исходными названием, текстом, тематикой и датой |
| `helper_postcomments` | `Comment` с автором, текстом и датой |
| `helper_requestpostedit` | Архивный комментарий с текстом и статусом принятия |
| `helper_liked` с `rating=1` | Один `Vote` соответствующего пользователя |

Положительные голоса пересчитываются по настоящим записям связей, а не по старым
денормализованным счётчикам. Dislike, рейтинги комментариев, флаг `verified` и
аватары не имеют прямого аналога в новой модели: они сохранены в исходном архиве,
но не представлены как новые активные функции. Ничего не объявляется
«проверенным исследованием» на основании старого булева флага.

Если email отсутствует, создаётся технический адрес `legacy-<id>@archive.invalid`;
для входа используется прежний username. Это не адрес доставки писем.
PBKDF2-SHA256 проверяется совместимо с Django; неизвестный алгоритм не
подменяется паролем по умолчанию.

## Проверка текущего снимка

В текущей среде перенесены 2 пользователя, 3 публикации, 4 комментария и
1 положительный голос. Повторный импорт не создал дубликатов. Автотест сравнивает
контрольную сумму исходного файла до и после операции.

Не запускайте старый Django-сервер для разработки новой версии. Архивные настройки
и зависимости не используются FastAPI.
